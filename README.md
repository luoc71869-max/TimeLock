# 时间锁 · TimeLock

给文件加一个时间锁：**设定一个时间点，在此之前文件只以密文存在，到点之后才能解锁。**

纯本机运行，不依赖任何第三方软件，使用 Windows 自带的 PowerShell 5.1 + WPF。

---

## 快速开始

双击 **`启动时间锁.vbs`**（推荐，不会闪控制台窗口）。

如果 `.vbs` 被安全软件拦截，可以双击 `启动时间锁.bat`。

> 首次运行如果出现 SmartScreen 或杀毒软件提示，是因为脚本没有数字签名。选择“仍要运行/允许”即可。所有代码都在本目录，可以直接打开查看。

系统要求：Windows 10 / 11，PowerShell 5.1（系统自带）。

---

## 使用方法

### 锁定

1. 在「锁定」页点击 **添加文件** 或 **添加文件夹**，选中的内容会显示在列表里。
2. 选择日期和具体时间（24 小时制），或用 `+1 小时 / +1 天 / +7 天 / +30 天` 快速设置。
3. 设置密码并确认（至少 6 位）。**留空 = 免密模式**，安全性较低（见下文）。
4. 确认输出位置，勾选「锁定成功后删除原文件」，点击 **立即锁定**。
5. 程序会联网校验一次时间，弹出摘要确认，然后生成一个 `.tlock` 文件并删除原文件。

### 解锁

1. 切到「解锁」页，点击 **浏览…** 选择 `.tlock` 文件，下方会显示解锁时间、文件数、大小和加密方式。
2. 输入密码。
3. 点击 **解锁**。程序先联网校验时间：
   - 未到时间 → 直接拒绝，并提示还剩多久；
   - 已到时间 → 解密并把文件恢复到原来的位置。
4. 若目标位置已有同名文件，默认跳过；勾选「覆盖已存在的同名文件」则覆盖。
5. 勾选「解锁成功后删除 .tlock 容器」可在解锁后自动删除容器。

## 它是怎么保护文件的

- **加密**：文件被打包、压缩，再用 **AES-256-CBC** 加密成一个 `.tlock` 容器。
- **完整性**：整个容器（含头部）由 **HMAC-SHA256** 保护。修改解锁时间、改动密文、截断文件，都会导致校验失败、拒绝解锁。
- **密码**：通过 **PBKDF2（300,000 次迭代）** 派生密钥，密码本身不写入磁盘、不上传网络。
- **免密模式**：随机密钥由 Windows **DPAPI** 保护，只有创建容器的 Windows 账户 + 电脑能解开。

## 时间是怎么判定的

解锁时间写入容器头部，并受 HMAC 保护。**判断“现在几点”只使用网络时间**：

1. 优先查询 NTP：`ntp.aliyun.com`、`cn.pool.ntp.org`；
2. NTP 失败时回退到 HTTPS 响应头里的服务器时间（百度 / 微软 / Cloudflare）；
3. 多个来源取**中位数**，来源之间差异超过 10 分钟则拒绝执行；
4. 记录上次校验的网络时间，发现倒退超过 24 小时会拒绝执行；
5. **完全无视本机时钟**，改系统时间没有用；
6. **无法联网时不会解锁**（锁定也需要联网校验一次）。

## 重要限制（请务必了解）

1. **密码丢失 = 数据永久丢失。** 密码不会被保存，也没有后门。请记牢或存进密码管理器。
2. **删除的原文件无法通过本工具恢复。** 机械硬盘上可能残留数据；SSD 上无法保证彻底擦除。
3. **请保留好 `.tlock` 文件。** 不要改名成其他扩展名、不要用文本编辑器修改，否则将无法解锁。
4. **免密模式安全性有限。** 同一 Windows 账户下的程序可以解开 DPAPI 密钥；只适合“防误触/防随手打开”。真正防别人请设置密码。
5. **这是本机工具，不是服务器托管。** 密码模式下，能同时拿到 `.tlock` 文件和密码的人，可以在别的电脑上用同样的格式解密。
6. **脚本是明文。** 懂技术的人可以修改脚本跳过时间检查——但在密码模式下，跳过检查仍然需要密码。时间锁的作用是让“提前打开”变得足够麻烦。
7. 建议对重要文件另做备份；跨时区/跨电脑使用时请确认时区设置正确。

## 常见问题

**改了系统时间，能提前解锁吗？**
不能。解锁判断只使用网络时间。

**断网了怎么办？**
无法解锁，会提示获取网络时间失败。这是刻意设计——否则改时间或拔网线就能绕过。

**能把 `.tlock` 发给别人吗？**
可以，但没有密码打不开。免密模式的容器换电脑/换账户后无法解锁。

**密码输错了会怎样？**
提示“密码错误，或文件已损坏 / 被篡改”。输错不会破坏文件，可以重试。

**可以锁定多个文件夹吗？**
可以，一次锁定会生成一个容器；列表里可以添加多个文件或文件夹。解锁时会恢复到各自原来的位置。

**容器能改名吗？**
可以改名，但不建议改扩展名（`.tlock`）。内容本身不受文件名影响。

**时间没到，但我真的需要里面的文件怎么办？**
没有办法——这正是时间锁的意义。请提前设置合理的时间。
